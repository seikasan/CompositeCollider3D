# Changelog

## [0.5.0] - 2026-09-26

- Added UPM package metadata and Runtime / Editor assembly definitions.
- Added package dependency declarations and bundled Windows x86_64 ManifoldNET and CoACD binaries.
- Added package and third-party license notices.
- Prepared user-facing documentation for release packaging.

## [0.4.0]

- Added manual and automatic generation modes, caching, and asynchronous Editor generation.
- Added CoACD advanced settings and generated geometry information.

## [0.3.0]

- Added the CompositeColliderSource3D component and custom Inspector.
- Added generated mesh asset saving and Collider material and layer settings.

## [0.2.0]

- Added BoxCollider, SphereCollider, and CapsuleCollider conversion.
- Added Difference and Intersect Boolean operations.

## [0.1.0]

- Added Merge for closed MeshCollider inputs and static or dynamic collision output.
